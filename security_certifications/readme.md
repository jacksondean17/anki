## Card Format

**Front:** Framework name (e.g., "SOC 2", "ISO/IEC 27001", "FedRAMP").

**Back:** A consistent fact sheet for each framework:
- **Category** badge
- **Type** — Certification, Regulation/Law, or Reference framework
- **Application / Industry** — who pursues it and why
- **Jurisdiction** — where it has force
- **Governing body** — who publishes/enforces it
- **What's included** — scope of the requirements
- **Strictness** — Low / Medium / High / Very High
- **Commonality** — Niche / Moderate / Common / Ubiquitous
