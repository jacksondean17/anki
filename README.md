## 🤖 Instructions for AI Assistants

When creating new Anki decks for this repo:

1. **Create the deck** - Generate the .apkg file in an appropriate subfolder
2. **Commit and push** - Add the .apkg file to git and push to your branch
3. **Update this README** - Add download links using this format:
   ```
   https://raw.githubusercontent.com/jacksondean17/anki/main/path/to/deck.apkg
   ```
4. **Instant availability** - Once merged to main, the raw GitHub URLs are live within seconds
5. **Mobile-friendly** - These links work perfectly on mobile browsers for direct download to AnkiDroid

**Key points:**
- Always use raw.githubusercontent.com URLs (not regular GitHub URLs)
- Point links to `main` branch for stability
- Links are instantly accessible after merge (no build/deploy delay)
- Test links work by accessing them directly in a browser
